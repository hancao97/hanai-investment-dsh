# 88AI 市场扫描交互核实

核实日期：2026-10-30。实际操作 [88AI 市场页](https://88aitou.com/market) 的桌面布局及公开免登录流程；没有执行加入自选、账户写入或交易。

## 已操作并确认

| 操作 | 页面行为与请求证据 |
| --- | --- |
| 打开桌面版 | 主页面是财务条件扫描器，而非移动布局中曾看到的特色榜单。默认按总市值倒序，公开 GET `/api/market/scan?sort_by=market_cap&sort_order=desc` 返回 `total` 和 `stocks`。本次返回总数 5574、行数 100；不是向前端下载全部股票后过滤。 |
| 优质低估 | 请求包含 `max_pe=20&min_roe=15&min_market_cap=10000000000`；市值参数为元，输入框以亿元显示。 |
| 高成长 | 请求包含 `max_pe=50&min_roe=10&min_net_profit_yoy=20`。 |
| 高股息 | Expert 开启时可见 `ROE≥8%`、`股息率≥3%`；关闭 Expert 时实测请求仅保留 ROE 条件。实现应避免这种静默丢弃条件的行为。 |
| 小市值价值 | 请求包含 `max_pe=15&min_roe=10&max_market_cap=50000000000`，即市值不超过 500 亿元。 |
| 蓝筹白马 | 请求包含 `min_roe=10&min_market_cap=100000000000`，即市值至少 1000 亿元。 |
| 重置 | 清除策略条件；重新显示无条件结果。 |
| Expert 开关 | 展开/收起市值、股息率、5 日净流、净利率、毛利率等高级输入；基础输入包括 PE/PB/ROE 范围、净利和营收增长下限。 |
| 点击 ROE 表头 | 发出 `sort_by=roe&sort_order=desc` 请求，返回排序后的前 100 行；不是仅在当前 100 行本地排序。 |
| 代码搜索按 Enter | 输入 `600519` 后按 Enter，跳转 `/analysis/600519` 个股分析；不能当成当前表格本地过滤逻辑。普通关键词查询的完整匹配/防抖规则未独立核实，不宣称已确认。 |
| 导出 | 实际触发 CSV 下载，文件名为 `market_scan_2026-10-30.csv`；未验证其是否包含全部匹配股票，不冒充全市场导出。 |
| 多市场信号 | 是单独扫描视图，市场有 A股/美股/加密资产，信号含 RSI、均线、MACD、放量等。实测美股 RSI 超卖向 `/api/assets/scan` 发出请求并返回 1 条研究级结果；并非财务条件接口。 |

## 原实现差异与接入前提

此前市场扫描实现仅将 `dashboard.get` 的榜单、板块样本作本地过滤，不能满足上述全市场财务条件和服务端排序语义。原有榜单请求不能充当财务扫描备源；不能把筛选当前 100 行当作筛选全市场，也不能把 `total` 当作实际已加载行数。

已实现独立的财务扫描查询/结果契约与快捷策略测试。用户已明确授权接入 88AI 公开汇总，已据此实现真实服务端财务查询并在 AGENTS.md 记录窄范围例外；此前榜单样本过滤已替换。后续公开 OpenAPI 核实还确认了 search、limit、offset，以及 snapshot_date 等响应字段。

接入其公开汇总时保留总匹配数与返回行数、原始缺失值、来源未提供统计期的限制；来源不可用时沿用同查询成功快照或明确不可用。财务报告期、报价日不能以请求日期冒充。源响应中部分指标返回 0，不能未经核实就把零转为缺失或反过来；原页面 5 日资金列显示破折号，不足以确认其统计完整性。
