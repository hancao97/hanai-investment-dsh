## 0. 最终结论

本轮可以保留一个有统计价值的买入候选：

**深跌且极度缩量后，放量收复 MA20。**

它不是“缩量就抄底”，而是等待三个阶段依次发生：

1. 价格从近 60 日高点至少回撤 25%；
2. 下跌过程中 `VMA5 / VMA60 ≤ 0.70`，卖盘和关注度明显冷却；
3. 此后出现强势日 K，成交量至少为 `VMA20` 的 1.5 倍，并从下方向上收复 MA20。

锁定规则后，在一组未参与选择的 132 只“逆风”历史成分股上进行 2024-01-01 至 2026-08-20 确认：

| 口径 | 信号 | 历史正收益率 | 平均净收益 | 对照基线 |
| --- | ---: | ---: | ---: | ---: |
| 次日开盘买入、持有 20 个交易日、事件间隔 20 日、扣费 | 105 | **58.10%** | **+4.99%** | 任意交易日买入为 48.48%、+0.85% |
| 完整动态进出场、扣费 | 117 | **40.17%** | **+2.66%** | 盈亏比 1.80，依赖少数较大盈利 |
| 完整动态进出场、双倍费用和滑点 | 117 | 39.32% | **+2.34%** | 盈亏比 1.67 |

20 日买点质量相对同市场、同时段基线提升约 **9.61 个百分点**，平均净收益提升约 **4.14 个百分点**。但必须同时看到：

- 20 日非重叠样本只有 105 个；
- 方向正确率的股票聚类 95% 区间为 **48.94%～68.89%**，下界仍低于 50%；
- 2024、2025 年完整策略平均为正，2026 年截至 8 月为负；
- 完整进出场胜率只有 40.17%，正期望来自“亏损较小、盈利较大”，不是高胜率；
- 预设的 10 项发布门槛只通过 6 项。

因此，产品当前可以显示：

- **红色“买入候选”**：表达历史上有正向筛选价值；
- **黄色“持仓防守退出”**：只针对由本策略产生的持仓；
- **橙色“风险增强”**：表达均线或成交量恶化；
- 不显示面向所有用户的绿色“确定卖点”。

## 1. 不能承诺什么，能够保证什么

任何只依赖历史价格和成交量的策略都不能保证未来成功率。市场状态、交易成本、涨跌停、停牌、公司事件和参与者行为都会变化。

系统能够保证的是**统计口径和执行口径不偷换**：

1. 规则固定版本，不按测试结果回填参数；
2. 信号只使用当时已经存在的数据；
3. 收盘产生信号，最早次日开盘成交；
4. 计入佣金、过户费、印花税和滑点；
5. 涨停无法买入时跳过，跌停无法卖出时延迟；
6. 同一股票同一时间只允许一个仓位；
7. 成功率同时展示样本、截止日期、持有期、费用和置信区间；
8. 影子运行继续积累新样本，不把 58.10% 固定成营销承诺。

## 2. 推荐的买入规则

### 2.1 名称与用途

- 策略 ID：`MA_VOL_VDR20_V0`
- 中文名：**深缩量 MA20 收复候选**
- 周期：前复权日 K
- 定位：20 个交易日左右的反转/修复候选，不是盘中超短线信号

### 2.2 指标定义

对第 `t` 个交易日：

- `MA20(t)`：最近 20 个交易日收盘价均值；
- `VMA5(t)`、`VMA20(t)`、`VMA60(t)`：最近 5、20、60 个交易日成交量均值；
- `High60(t)`：不含当日的前 60 个交易日最高价；
- `CloseLocation(t) = (Close - Low) / (High - Low)`；若最高等于最低，取 0.5。

### 2.3 前置“冷却区”

信号日前 20 个交易日内，至少存在一天同时满足：

```text
VMA5 / VMA60 <= 0.70
Close <= MA20
Close / High60 - 1 <= -25%
```

这表达的不是“成交量越小越好”，而是：股价已经明显回撤，短期成交量相对长期常态极度收缩，市场进入冷却状态。

此外，信号日前 20 个交易日中至少有 10 天收盘价低于各自的 MA20，避免把普通上涨途中的小回踩误判为深跌修复。

### 2.4 收盘确认

信号日必须同时满足：

```text
昨日 Close <= 昨日 MA20
今日 Close > 今日 MA20
今日 Volume / 今日 VMA20 >= 1.50
今日 Volume / 今日 VMA20 <= 3.50
今日 Close > 今日 Open
CloseLocation >= 0.65
```

上限 3.5 倍用于避免把极端事件量一律解释为健康确认。成交量很大但收盘靠近最低价，属于抛压或分歧，不属于本买点。

### 2.5 成交规则

1. 信号只在日 K 收盘后确认；
2. 下一交易日开盘买入；
3. 若下一开盘处于估算涨停价，信号记为“不可成交”并跳过，不追涨排队；
4. 不在信号 K 的收盘价假设成交；
5. 不用后来才出现的数据把标记补回过去。

### 2.6 伪代码

```text
dry_setup = any(previous 20 bars where
    VMA5 / VMA60 <= 0.70
    and Close <= MA20
    and Close <= High60 * 0.75
)

below_days = count(previous 20 bars where Close < MA20)

buy_candidate = dry_setup
    and below_days >= 10
    and PrevClose <= PrevMA20
    and Close > MA20
    and 1.50 <= Volume / VMA20 <= 3.50
    and Close > Open
    and CloseLocation >= 0.65
```

## 3. 推荐的退出规则

卖出规则必须绑定本策略的入场价和持仓年龄。脱离持仓上下文，仅凭“跌破某根均线”无法得到稳定的通用卖点。

### 3.1 强制风险边界

按收盘确认、次日开盘执行：

- 收盘相对入场开盘价亏损达到 **-10%**：防守退出；
- 收盘相对入场开盘价盈利达到 **+25%**：止盈退出；
- 持有达到 **20 个交易日**：时间退出。

这是研究中的固定口径。真实产品若改变止损、止盈或持有期，必须产生新策略版本并重新回测。

### 3.2 均线防守退出

入场后的前 5 个交易日不因普通均线抖动退出，但 -10% 收盘止损和 +25% 止盈仍有效。第 5 日以后，满足任一条件则在次日开盘退出：

1. 前一日之前仍在 MA20 上方，随后连续两个收盘低于各自 MA20；
2. MA5 从上向下跌破 MA10，并且当日收盘同时低于 MA10。

第一条防止单日假跌破；第二条处理短期动量已经转弱但 MA20 尚未完成双日确认的情况。

### 3.3 放量衰竭退出

只有下列条件同时出现才作为持仓退出，而不是看到巨量就卖：

```text
过去 20 日涨幅 >= 20%
当日成交量 >= 2.5 * VMA20
CloseLocation <= 0.40
Close < MA10
```

含义是“上涨后极度放量＋收盘位置弱＋已经跌到 MA10 下方”。单独的放量可能是突破、换手或信息到达，方向并不唯一。

### 3.4 跌停约束

若计划卖出的次日开盘处于估算跌停价，回测不会假设能够成交，而是将退出顺延到首个可执行开盘。产品必须显示“退出等待成交”，不能显示已经卖出。

## 4. MA5、MA10、MA20、MA60 应分别怎样使用

### 4.1 本轮实证

第一轮对每根均线分别测试了单日/双日跌破以及 0、1.2、1.5 倍成交量过滤。每个周期先按 2015—2020 选择参数，再观察 2024—2026 测试结果：

| 跌破规则 | 非重叠事件 | 后续 20 日方向正确率 | 平均方向收益 | 结论 |
| --- | ---: | ---: | ---: | --- |
| MA5 | 114 | 37.72% | -1.92% | 噪声大，不能作为通用卖点 |
| MA10 | 800 | 49.88% | -1.67% | 接近随机且平均反向 |
| MA20 | 123 | 39.02% | -3.10% | 单独卖出会错过大量修复 |
| MA60 | 87 | 32.18% | -6.54% | 滞后严重，样本小且跨阶段失效 |

这里“平均方向收益”为负，表示发出卖出信号后股票反而上涨。所有周期的六个参数变体在测试期平均方向收益区间均包含或完全落在负值区域。

### 4.2 产品语义

| 均线 | 推荐用途 | 不推荐用途 |
| --- | --- | --- |
| MA5 | 短期速度、与 MA10 的交叉证据 | 一日跌破即卖 |
| MA10 | 持仓防守线、需双日或 MA5 交叉确认 | 面向无持仓用户的确定卖点 |
| MA20 | 买入收复线、持仓主要防守线 | 所有股票跌破都标绿色“卖” |
| MA60 | 中期市场状态和趋势背景 | 作为快速止损线 |

结论是：均线不是四个彼此独立的买卖按钮，而是一套分层证据。

## 5. “极度缩量”和“极度放量”的正确解释

### 5.1 缩量不能直接买

中国股票样本研究发现，短期与长期成交量均线距离对未来收益存在负向预测关系，即近期成交量过热往往对应较低后续收益；但这类研究主要是横截面和月度持有期证据，不能直接变成日线买点。[Ma、Yang、Su（2021）](https://doi.org/10.1016/j.pacfin.2021.101494)

本方案把极度缩量只当作“冷却区”，必须等待放量收复 MA20 才确认。这样避免在下降趋势中不断接飞刀。

### 5.2 放量不能直接卖

成交量既可能代表信息确认和趋势延续，也可能代表过度关注和反转。经典研究显示成交量会影响动量的强度与持续性，而中国市场研究也观察到高量与后续收益之间的关系受市场结构影响。[Lee、Swaminathan](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=92589)、[Wang、Chin（2004）](https://doi.org/10.1016/j.pacfin.2003.12.002)

本轮独立卖出确认也给出反例：开发期选出的“上涨 20% 后连续两日跌破 MA5”在逆风确认集有 167 个非重叠事件，后续 20 日方向正确率只有 **41.92%**，平均方向收益 **-4.92%**，95% 聚类区间完全偏负。

因此，极度放量只能先触发“分歧/衰竭观察”，必须再结合弱收盘和持仓均线破坏。

确认集定义为：

```text
union(2015, 2021, 2022, 2023 历史成分股)
- union(2024, 2025, 2026 历史成分股)
```

共 132 只股票。它们在 2024—2026 的结果没有参与新规则选择，而且没有进入任何近年 cohort，因此比只测试当期热门成分股更苛刻。它不是市场代表性组合，不能单独外推到所有 A 股。

- 过户费：每边 0.001%；
- 卖出印花税：0.05%；
- 滑点：每边 0.10%；
- 双倍摩擦测试将上述成本和滑点整体乘二；
- 日线信号收盘确认，次日开盘成交；
- 遵守 T+1，估算涨跌停可执行性。

交易约束和费用来源见[上交所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/fund/trading/c/c_20260424_10817739.shtml)、[上交所交易费用](https://one.sse.com.cn/onething/gptz/)、[深交所收费说明](https://www.szse.cn/marketServices/deal/payFees/index.html)和[证券交易印花税说明](https://shanxi.chinatax.gov.cn/web/detail/sx-11400-545-1780448)。

本轮预设 10 项历史发布门槛，通过 6 项：

| 门槛 | 当前结果 |
| --- | --- |
| 确认期完整交易 ≥150 | 未通过：117 |
| 完整交易胜率 ≥52% | 未通过：40.17% |
| 胜率 95% 区间下界 ≥48% | 未通过 |
| 平均净收益 >0 | 通过 |
| 平均净收益区间下界 >0 | 通过 |
| 盈亏比 ≥1.20 | 通过：1.80 |
| 去掉最赚钱 5% 后仍为正 | 通过：约 +0.02% |
| 双倍摩擦后仍为正 | 通过：+2.34% |
| 三年中至少两年平均为正 | 通过：2/3 |
| 中位股票策略 CAGR >0 | 未通过：大量股票无信号，结果为 0 |

所以当前正确产品标签是：**研究候选，6/10 门槛通过**。

升级为普通用户可见的明确提醒前，至少还需要：

1. 累计达到 300 个真正样本外、非重叠事件；
2. 20 日方向正确率 95% 区间下界稳定高于 50%；
3. 至少四个不同市场状态年度平均为正；
4. 预注册并验证市场状态过滤，而不是事后修补 2026；
5. 在另一数据供应商上核对信号日、复权价和成交量；
6. 完成组合层并发持仓、行业集中和流动性容量测试。

简单技术规则在考虑数据窥探后经常无法稳定超越持有基准，这也是本方案坚持锁参和独立确认的原因。[中国指数技术规则 Reality Check 研究](https://arxiv.org/abs/1504.04254)、[Lo、Mamaysky、Wang](https://www.nber.org/papers/w7613)

### 9.3 自选列表

新增两列：

- 信号状态：`冷却观察 / 收盘候选 / 持仓防守 / 风险增强`；
- 关键证据：例如 `缩量 0.62 · 回撤 -31% · 放量 1.83`。

列表只消费后端已经固化的信号快照，不在前端重新计算。

### 9.4 提醒

提醒分为：

1. 收盘买入候选；
2. 次日不可成交；
3. 持仓防守退出待执行；
4. 跌停导致退出延迟；
5. 20 日观察结果到期。

同一股票、同一策略版本、同一交易日必须幂等，避免重复通知。

## 11. 实施顺序

### Phase 0：研究层

- 将公式实现为纯函数；
- 对缺少 120 根日 K、成交量缺失和停牌状态返回不可评价；
- 写逐根 K 线因果测试和边界测试；
- 生成不可变信号快照，不接交易接口。

### Phase 1：内部影子运行

- 每个交易日收盘后批量计算；
- 次日记录是否可成交及模拟成交价；
- 第 5、10、20 日自动结算评价；
- 页面仅内部账号可见。

### Phase 2：研究信号上线

- 默认关闭；
- 显示样本、基线、置信区间和版本；
- 不发送“建议买入/卖出”措辞；
- 用户可加入观察，不支持自动下单。

### Phase 3：重新校准

只有新增样本达到预注册门槛后才能发布 V1。参数变化必须新建版本，不能覆盖 V0 的历史结果。

## 13. 最终产品决策

1. **接受** `MA_VOL_VDR20_V0` 作为内部“买入研究候选”；
2. **接受**与入场绑定的 MA20/MA5-MA10 防守退出、收盘止损、止盈和时间退出；
3. **拒绝**“极度缩量直接抄底”；
4. **拒绝**“极度放量直接卖出”；
5. **拒绝** MA5/10/20/60 任一单独跌破就显示通用卖点；
6. **拒绝**对外宣称 58.10% 是未来保证；
7. **进入影子运行**，继续积累至少 195 个非重叠样本，使总量达到 300，再重新评审。

这是目前证据能够支持的最强方案：有明确规则、有可复现的正向样本外结果，也明确保留了它尚未通过的门槛。
