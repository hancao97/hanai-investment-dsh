## 三、行业案例如何影响本次实现

### AlphaSense

- 参考点：生成式搜索、跨来源研究、监控与可回到证据的研究体验。
- 本次落地：报告来源与证据账本、结构质量卡、持续研究收件箱。
- 参考资料：[Generative Search](https://www.alpha-sense.com/platform/generative-search/)、[What is AlphaSense](https://www.alpha-sense.com/resources/product-articles/what-is-alphasense/)

### Koyfin

- 参考点：可定制 Watchlist、历史数据与提醒共同构成日常研究入口。
- 本次落地：自选研究覆盖、独立异步估值、刷新、状态筛选和逾期任务。
- 参考资料：[Watchlists](https://www.koyfin.com/features/watchlists/)、[Historic data in watchlist and screener](https://www.koyfin.com/help/release-notes/v3-67-historic-data-in-watchlist-screener/)

### Quartr

- 参考点：检索、原始资料、Watchlist、提醒和公司对比彼此连通。
- 本次落地：来源跳转、跨报告待办、同股异见和版本变化。
- 参考资料：[Quartr features](https://quartr.com/features/index)

### OpenBB Workspace

- 参考点：可组合研究工作台和保留来源语义的 Widget，而不是单一聊天窗口。
- 本次落地：自选覆盖台、研究待办、命题复盘、报告审计和同股比较均成为独立业务组件。
- 参考资料：[Workspace](https://docs.openbb.co/workspace)、[Widgets overview](https://docs.openbb.co/workspace/analysts/widgets/overview)

### Fiscal.ai

- 参考点：精确回到原始 PDF、持续观察“发生了什么变化”，避免无出处摘要。
- 本次落地：证据行强制 URL/日期、版本变化、到期复核与不可改写校准记录。
- 参考资料：[MCP and Skills guide](https://docs.fiscal.ai/docs/guides/mcp-skills)

## 五、明确边界与暂未实现

- [ ] 历史报告不会被后台重写成新证据格式；它们只会显示结构缺口。需要用户显式修订才生成新版本。
- [ ] 当前审计只能证明结构和链接可观察，不能自动证明来源权威、链接内容与主张完全一致或结论正确。
- [ ] 价值大师网数据仍标注“个人研究接口，未获再分发授权”；慢或不可用时不阻塞自选行情。
- [ ] 尚未接入公告/财报事件流自动创建待办；当前待办来自报告建议或用户手动创建。
- [ ] 命题结果仍由用户按既定口径确认，系统不会自行裁决，也不会据此给出买卖信号。
- [ ] 同股异见比较现有已封存报告，不会为了凑齐观点自动新建大师任务或制造共识。
- [ ] 尚未实现完整研究委员会 DAG、同业矩阵、情景实验室、PDF 精确页码/段落引用和后台来源监控。
- [ ] 当前仍是桌面优先布局；较窄窗口做了主要降级，但未把移动端作为本轮目标。

## 六、建议的下一轮优先级

1. 法定公告与财报事件入口：先做授权清晰、可稳定抓取的一手来源，事件到来后匹配受影响主张和到期待办。
2. 引用定位升级：在 URL 之外保存文档标题、页码/段落、摘录哈希和抓取时间，并提供原文侧栏。
3. 同业与跨期矩阵：先限定关键 KPI 和叙事变化，避免做成宽而浅的通用筛选器。
4. 研究委员会 MVP：冻结共享证据包，让多空审阅者独立输出结构化异议，再由大师主笔；不先追求 Agent 数量。
5. 校准复盘：按大师、命题类型和概率区间聚合 Brier 历史，但只有样本足够时才显示统计结论。
