# 宏观数据：主题、指标与后台序列

## 页面边界

`#/dashboard/macro` 使用五个主题 Tab：市场资金、货币与信用、经济景气、通胀与利率、市场广度。一个主题包含多个图表，不给每条指标线单独创建 Tab。

- `market-macro.tsx` 管理主题和各自已应用的日期范围；切换主题后保留选择，卸载旧主题的观察器。
- 市场资金复用现有 ETF 双图、取数链路与历史兼容接口。
- `macro-indicators.tsx` 渲染经济指标卡片；同主题共享日期工具栏，各卡片独立显示覆盖时间、取数失败和数据详情。
- `macro-indicator-chart.ts` 负责图表选项，复用 EChart 与主题配色。月频按月末坐标绘制，补出的月份坐标只有 null，没有伪造数值；不跨缺失月连线。工业和消费若已有真实1—2月合并报告，累计线省略缺失的1月占位，按实际公布期连接，在2月观测点标明“1—2月”；单月同比仍保留1、2月缺口，其它缺失月份也继续断线。日频保留来源报价日期。
- 市场广度默认近三个月，后台尝试取得最近一年并显示实际覆盖；其余主题默认最近应收盘工作日起向前五年。单次区间最长五年，范围限制不等于数据保存期限，不清除更早数据。
- 来源、获取时间、公式及诊断放在默认折叠的详情中；M1口径调整等影响解读的关键信息保留在摘要。

## 指标目录与口径

契约 `packages/contracts/src/macro-indicators.ts` 的 `MACRO_TOPICS` 和 `MACRO_INDICATORS` 是唯一目录，定义稳定 ID、主题、名称、频率、单位、列、图形类型和说明。目录不存网络地址或第三方字段名。界面按目录生成卡片；前后端共用同一 ID 联合类型。

| 主题 | 指标 | 实际口径 |
|---|---|---|
| 市场资金 | 沪深300 ETF规模与占比 | 保留既有日频/月报与重建参考口径 |
| 货币与信用 | 社融 | 当月社融增量，亿元，非存量 |
| 货币与信用 | 信贷 | 金融机构当月新增人民币贷款，亿元 |
| 货币与信用 | M1/M2 | 来源直接公布的同比，%，2025年起M1口径调整 |
| 经济景气 | PMI | 制造业PMI、非制造业商务活动指数；50荣枯线 |
| 经济景气 | 工业生产 | 规模以上工业增加值当月同比、累计同比，% |
| 经济景气 | 消费 | 社会消费品零售总额当月同比、累计同比，% |
| 通胀与利率 | CPI | 全国同比、环比，% |
| 通胀与利率 | PPI | 全国工业生产者出厂价格同比，% |
| 通胀与利率 | 国债收益率 | 中国2/5/10/30年期日频收益率，% |
| 市场广度 | 阿姆氏指标 | 88AI 沪深京 A 股含 ST；成交额版 TRIN、涨跌家数比和涨跌成交额比，估算点单独标记 |

月度统计期不是发布日期。接口未提供逐期发布日期，不能推断或把月初/月末当作发布日。1—2月合并发布时，当月缺失仍为 null，累计同比独立保留。所有范围展示当前来源核实序列，可能含历史修订，不是历史时点可知数据。

## 来源与验证

`packages/domain/src/providers/macro-indicators.ts` 实现传输字段到业务列的映射，依赖现有 `HttpClient`、`Clock` 和 `SourceCircuit`。

- 月度经济指标：东方财富公开 `datacenter-web.eastmoney.com/api/data/v1/get`，按报告名和统计期查询；国债报告为 `RPTA_WEB_TREASURYYIELD`，逐页取齐。公开 v1 无需 AKShare 旧版接口中的 token。
- 社融：商务部商务数据中心公开 POST `data.mofcom.gov.cn/datamofcom/front/gnmy/shrzgmQuery`，原始来源为中国人民银行。
- 用户指定的 88AI 阿姆氏接口分别用于盘中和日线。数据采用成交额而非标准成交股数；历史数据可能估算或缺失。日线中的当天记录须经当日 15:00 分时点确认，未确认不写入收盘历史；统计范围与其他宽度来源独立。
- 88AI 日线接口单次最多请求 250 条；不足一年时保留实际覆盖并显示部分缺失，不把未返回区间标为已覆盖。页面按量能比、涨跌比展示曲线及 1.0 基准，TRIN 同时展示为柱状图和摘要。
- 使用 AKShare 的公开上游，不增加 Python 运行服务或依赖，不使用登录态。
- HTTP失败、报告无效、字段缺失、全部空值均失败；不得当作空结果成功覆盖已有序列。零值和负值保留。
- 新能力复用源熔断：连续失败3次，冷却5分钟；不改动既有行情备源顺序，不使用口径不匹配的备源。
- 2026-10-29实测：七类月度报告最新到2026-09，国债到2026-10-28；商务部社融只到2026-04。来源落后必须展示真实最后统计期，不称为最新已发布宏观数据。

接口与字段参考 [AKShare宏观源码](https://github.com/akfamily/akshare/blob/main/akshare/macro/macro_china.py)、[AKShare国债源码](https://github.com/akfamily/akshare/blob/main/akshare/bond/bond_em.py)；社融原始来源见[商务部数据页](https://data.mofcom.gov.cn/gnmy/shrzgm.shtml)，M1口径见[人民银行公告2024年第17号](https://www.pbc.gov.cn/chubanwu/fileDir/resource/cms/2025/06/2025062416082199683.pdf)。接口可用性以本次实际取数为准。

## Host、存储与失败语义

RPC `market.macro.indicators` 接收注册主题、五年内日期范围和可选手动刷新标记，不接受任意URL/报告名。服务端校验不依赖前端控件。

`MacroIndicators` 是经济指标的持久任务协调器。ETF 的 `MacroSeries` 保留原工作器，同一个 Host 调度时钟每分钟检查北京时间20:00时槽，并调用经济指标协调器；不增加独立页面实时轮询，也不新建外部服务。

- 查询先返回本地已保存值；未检查范围、无数据或月度尾部缺口异步入队。重复/重叠同主题范围合并，合并后仍不超过五年。
- 主题间排队，同主题指标并发；每项一完成就独立保存，一个来源失败不影响其它卡片。
- 经济指标状态键为 `macro.indicators.work`，包含队列、时槽及尝试结果。活动任务在持久队列中直到结束；关闭Host不删除待办，重启时由统一时钟恢复。
- 自动缺口重试至少六小时，手动请求至少60秒；后台按日检查近期数据和修订。已覆盖范围增量复查近13个月月度报告、国债尾部10日，未覆盖旧区间完整请求；若实际缺口早于近端复查窗口，从缺口处续取。月度报告缺期/缺字段标记为partial并持久重试，工业/消费1—2月合并发布不误判为单月缺口；日频仅判断已返回观测中的空字段，不推断假日缺数。
- 页面两秒观察只在当前范围有后台工作时运行，切换/离页仅取消RPC观察，不能取消Host取数。
- 来源失败沿用本地值，保留原来源与获取时间。部分空字段不能擦除已有核实数值；没有旧观测时仍留空，真实零值、负值和非空修订照常更新。来源成功但尚未收录尾部数据仍显示实际覆盖，不能填平尾部。

所有数据仍进入统一 `MarketHistoryStore` 的 `macro.series` 月桶（日期键为每月1日），没有新表，没有每天复制整张五年图。`MacroSeriesData.indicators` 为向后兼容的可选映射，既有ETF字段及旧 `macro.chart` 保留。桶更新通过 `selectMacroSeries` 合并所有分项：更新ETF不删经济指标，反之亦然，切范围及清理行情缓存也不删除业务历史。

`meta.fetchedAt` 表示该分项最近成功取数时间，`sourceTimestamp` 是来源已核实的最新统计期（合并旧区间查询时不能倒退）；图表另列所选范围实际覆盖。它们不能作为每个历史点的单独发布时间或观察时间。

## 添加指标的最短路径

1. 在 `MACRO_INDICATORS` 增加定义，优先放入已有主题。不同单位或不同口径用独立卡片，不在同轴混画。
2. 在提供器增加已实测的报告/字段映射；新增协议则在同层增加专用适配器。不得把第三方原始字段泄漏到页面。
3. 用真实响应结构建立测试：日期、单位、零负值、空值、分页、失败和历史覆盖。通用存储校验按目录检查列；特殊语义补专门校验。
4. 复用RPC、队列、月桶、页面卡片和图表生成，无需新增面板快照表或逐指标端点。
5. 如果新增主题，补主题联合类型、RPC白名单和调度主题列表，并覆盖排队/范围状态测试。
6. 跑相关回归、完整typecheck/Vitest/build，并用真实公开数据渲染验证。构建成功不等于真实DSH宿主已经重启。

当前只实现这些已请求指标；没有加入可视化编辑器、动态插件注册或用户自定义网络地址。
