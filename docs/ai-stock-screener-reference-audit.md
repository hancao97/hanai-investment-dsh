# 88AI AI选股交互核实

核实日期：2026-10-30。实际操作 [AI选股页面](https://88aitou.com/search)，并阅读公开 [OpenAPI](https://88aitou.com/openapi.json)。未操作加入自选或交易，没有使用登录账户或私有接口。

| 操作/证据 | 实际观察 |
| --- | --- |
| 打开页 | 展示6个示例、历史数量、当前状态和自然语言输入。 |
| 选择示例 | 填入问题，仍可编辑；按 Enter 提交。 |
| 提交银行问题 | 观察到 POST `/api/market/ai-screen`，请求体含 `query` 和 `limit:20`。输入为「低估值高分红的银行股」。 |
| 响应结构 | 实际响应包含 results、query、explanation、filters、effective_filters、filter_mode、field_coverage、total_candidates、query_id、query_time_ms。股票项包含名称、价格、财务指标、rationale、score及主题匹配字段。 |
| 返回结果 | 页面显示候选数量、耗时、已筛候选池数量；卡片含逐股理由、指标、自选/K线/深度分析入口。 |
| 明确数值问题 | 输入「市值100亿以上ROE超15%的」，页面解释只列出市值要求，卡片中仍有ROE低于15%的公司。此观察不能证明每项原始条件都被执行，重现时必须显示实际执行条件，不照搬“完全符合”的文案。 |
| 历史入口 | 未登录状态历史计数为0，操作入口没有可验证的历史记录；未声称验证了登录态历史保存或重跑。 |

本项目重现的是自然语言→可验证条件计划→真实候选及依据→本地历史的流程。解析使用已有DSH会话/模型，执行使用已授权的公开财务扫描源，不额外接入88AI的AI推理服务。模型不提供候选事实或未经验证的分数。

对数据源无法执行的季度连续性、真实订单、量价形态、主题或指定财报期等条件，明确列为待核实；模糊阈值须确认。用户确认初筛后这些缺口仍显示，不暗中忽略原问题条件。旧版聊天历史保留，并与新结构化查询区分。
