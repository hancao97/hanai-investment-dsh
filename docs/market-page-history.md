# 今日市场历史记录

今日市场顶部可选择日期，或从“已保存历史日期”打开本地记录。“返回今日”恢复默认加载策略和开市轮询。选择今天的日历日期进入今日视图；若要查看今天已经保存的静态记录，从已保存日期列表选择今天。

日期列表仅统计今日市场面板（包括海外指数和板块下钻），排除 `macro.*` 宏观序列、输入及旧图表记录。两类数据仍共用统一历史表：列表查询使用 `MarketHistoryStore.list('market')`，宏观内部保留默认完整查询和按日期读取，不删除任何业务记录；混合日期的列表保存时间仅按市场面板计算。

今日市场所有面板及放大弹层统一隐藏成功时的来源、时间和实时/最新标签；国内休市时显示“休市缓存”，显式历史显示“历史快照”，错误优先显示对应区块的失败信息。宏观等独立页面不受此规则影响。

## 保存与查看

- 默认加载复用 `isMarketOpen` 策略：窗口外先读取不晚于今天的最近一份可读本地归档，显示“休市缓存”和记录日期；归档须覆盖最近应收盘工作日的八类面板。有精确来源时间的数据以当日 15:00 或之后的行情时间确认已收盘，获取时间须不早于行情时间；只有日期或无来源时间的面板须在当日 15:05 后取得。满足条件才直接复用，不请求行情源或改写原获取时间。指数还逐项检查，不能用最新一项掩盖保留的盘中旧项。
- 旧日期、盘中记录或缺失面板会触发一次自动取数并由现有 Host 路径更新归档，不启动手动冷却；失败时保留旧归档并提示。没有归档则正常取数，读取本地失败则明确报错。显式选择历史日期仍只读，不自动补实时数据。最近应收盘日按北京时间工作日推算，仍不等于完整节假日交易日历。
- 休市快照保留手动刷新按钮，点击才主动取数，并继续执行 60 秒冷却。自动跨过开盘边界时恢复行情轮询，显式选择的历史日期继续保持只读；休市快照的板块下钻只读已归档成分。

- 打开今日市场、开市自动轮询、手动刷新取得的成功结果均自动保存，不增加行情源请求。
- 当前归档包括指数与两市成交额、独立市场宽度、行业热力、概念热力、涨幅榜、跌幅榜、成交额榜、换手率榜。板块成分在实际下钻取得后保存。
- 市场宽度下的九档涨跌分布使用独立 `market.distribution` RPC，按 `distribution` key 复用统一历史表。参考 stock-quiz 的降序分页二分算法，只读取区间边界页并复用已读页；取数顺序为腾讯全 A 股排行 → 新浪 `hs_a` → 东财沪深 A 股列表，均包含 ST，口径与乐咕宽度各自独立。腾讯使用现行公开行情页的 `rank/hs/getBoardRankList`，`board_code=aStock`、`sort_type=priceRatio`，覆盖沪深京；不能用 `rank/pt/getRank` 板块排行替代。腾讯末尾的 `state=S` 停牌记录在二分前独立核验，只有明确零涨幅才计入平盘，缺失值不会补零。它仍是多次请求，不是单次汇总接口；每源整次限时10秒（可由服务超时配置调整），失败沿用快照，不阻塞其它面板。盘中缓存25秒、休市6小时，通用熔断连续失败3次冷却5分钟。无来源日期的数据仅在 Host 已核实采集日市场日期后归档；无法确认则不写入历史。显式历史只读本地，旧日期无分布时明确提示。
- 分布区间为 `<-10%`、`[-10%,-5%)`、`[-5%,-2%)`、`[-2%,0)`、平盘、`(0,2%)`、`[2%,5%)`、`[5%,10%)`、`≥10%`；两端区间不是涨跌停家数。按来源样本统计，不能与其它宽度源混合补桶。
- 涨跌家数条下方展示两市成交和昨日成交，均复用 `overview.breadth.totalAmount`。昨日值按所选数据日期的前一工作日（跳过周末）读取本地 `overview` 收盘归档，不以盘中或更早记录代替，缺失显示“—”，读取失败在面板头提示；此策略不充当完整交易日历，节假日缺口也不会用其它日期冒充。切换历史日期不调用实时接口补成交额，自动更新历史目录不重复读取相同归档。
- 涨停梯队与题材连板分布位于市场宽度/大盘异动下方，复用独立 `market.ladder` RPC 与统一历史表 `ladder` key。开市每30秒更新、盘中缓存25秒、休市6小时；手动刷新使用整页冷却，失败保留最后成功数据。显式历史仅查看本地记录，旧归档缺失梯队时不补实时。
- 涨停池按同花顺→东财兜底顺序，两个来源均使用通用 SourceCircuit（连续失败3次冷却5分钟）且独立计数；同花顺一次最多200只、最多3页，池数量或日期不完整、无法确认连续涨停数时回退。合法N天M板造成的连续数能力缺口不累计接口失败，避免误熔断后丢掉仍然可用的题材、板型；网络及无效响应仍按连续3次失败冷却5分钟。沿用 `dsh-plugin` 的公开接口参数，未移植整套交易页。东财兜底才读取其涨停/炸板/昨日涨停池，题材用同花顺热点归因备用；无法获取时保留梯队、题材留空并在头部报错，不把所属行业冒充涨停原因。池内筛选范围以来源为准，不与市场宽度家数拼接。
- 今日梯队与昨日涨停今日表现采用两条紧凑摘要，空间不足才换行；首板展开不改变双栏等高规则。昨日表现优先读取同花顺上一工作日涨停候选池，再复用腾讯优先的批量报价取得目标日涨幅；不扫描全市场。候选日按工作日推算，节假日/缺失样本由东财昨日涨停池兜底，不冒充完整交易日历。任一报价缺失或非目标日不按零值补齐；平均/中位涨幅、翻红/翻绿/平盘由完整样本计算，保留各自来源元数据并复用 `ladder` 归档。旧快照缺失该字段时默认视图补取一次，显式历史只读并显示“—”。
- 板型仅显示来源明确标注的一字板、T字板、换手板；不按炸板次数推断，缺失显示“板型待确认”。同花顺完整同日数据即使无法提供连续板数，其板型和题材仍可按代码补入东财兜底结果。新结果带 `method: source-board-types-v1`，默认视图补取旧版无标记快照一次，显式历史仍只读。连板只认连续涨停，N天M板不直接当作M连板。同花顺汇总的晋级率为当日连续2板及以上家数/昨日涨停池家数；东财兜底使用昨日涨停代码与当日涨停代码交集/昨日样本数。炸板率为当前未封板炸板家数/（当前涨停+当前未封板炸板家数），不是炸板次数占比；零分母或缺失样本显示“—”。题材按涨停原因标签去重聚合，一股可归属多个题材，不能将各题材家数相加充当总涨停家数。首板默认展示6只并可展开，全部连板与断层保留，封板时间、回封次数和完整原因可在个股悬停查看。
- 大盘异动面板复用 `dsh-plugin` 的上证分时叠加板块异动展示方式：`market.intraday` 复用腾讯→东财分时链，`market.signals` 读取同花顺公开板块异动快讯。按 `intraday`、`signals` 两个面板 key 独立保存到统一历史表，快讯失败不阻塞分时和其它面板。两者均按实际分时交易日归档，历史缺失时明确提示，不请求实时接口补齐。
- 异动快讯保留当天各时刻事件，不再只取每板块最早一条或截取前8条；同分钟、同板块、同方向的重复快讯去重。板块名和方向取自标题的板块主句，排除午评、收评、外围行情和午休，不受后文个股涨跌干扰。只标注能对应上证分时分钟的同日事件，名称直接显示在图上，悬停查看原始快讯；成功时隐藏行情来源与时间，错误才在面板头显示。它是同花顺公开快讯标注，并非全市场扫描或参考站自有`market_yidong`的同源复制。
- 新归档带`method: ths-sector-events-v2`；默认视图会重新获取旧版截断的快讯快照，显式历史仍只读旧记录并注明不完整。公开新闻源独立受通用熔断保护，完整覆盖目标日期才接受空信号；分页最多8页且整次读取预算6秒，超出后保留上次快照。腾讯指数成交额/成交量不等于指数点位均线，因此不据此伪造均价线。
- 指数区域现有 8 个境内指数与 5 个海外参考指数。海外通过独立 `market.indices` RPC 批量加载，按 `global.indices` 面板复用同一张历史表；归档日期为北京时间观察日，每项保留自己的 `marketDate` 和原始来源时间，因此纳指上一美国交易日可以出现在今日观察快照中。显式历史模式不发海外实时请求。
- 国内休市（含午休）时，海外指数只读最近本地归档或内存缓存，手动请求也不访问行情源；无缓存显示不可用。国内开市后恢复海外轮询，采用香港、纽约、东京、首尔与上海时区及各自工作日时段，纽约通过 IANA 时区处理冬夏令时；活跃时缓存25秒，其余6小时。各源连续失败3次冷却5分钟，失败沿用带原时间的旧值或显示不可用，诊断中独立列出“海外指数”。A50 仅用现货 `b_FTXIN9` / `100.XIN9`，不替换成期货或 CFD；黄金和原油不接入。
- 默认视图会分别寻找最近境内归档和最近海外归档；美股跨北京时间零点生成的海外单面板记录，不会遮蔽上一交易日的境内快照。旧的六指数归档会保留，新加品种未采集时显示缺失；境内默认视图可自动补新，海外须等国内开市后补取，显式历史视图不伪造补齐。
- 每个日期、每个面板保留最后一次成功记录；各面板独立更新，失败不会清空其它面板。它是每日面板快照，不是盘中逐笔或分钟回放。
- 归档日期优先使用来源时间，市场宽度使用其统计日期。缺少来源时间的板块、榜单和成分股仅在本次指数确认的市场日期、北京时间采集日与当前日期一致时归档，且必须为新取数结果；缓存不重新绑定日期。指数失败或日期不能确认时跳过这些面板，保留原归档，避免旧指数把新数据写回前一天，或旧缓存混入新日期。
- 境内与海外指数均按代码合并来源时间更晚的报价。部分返回时，成功取得的指数继续更新，缺失项保留各自原值和原来源时间；来源及行情时间仍保留在数据和归档中，成功时不显示在指数面板头。海外观察日使用批次原获取日期，跨午夜复用缓存不会生成新日期归档。两市成交额仅在本次有效结果同时包含沪深两个指数时计算，不能把新成交额与保留的旧成交额相加。
- 腾讯收盘报价可能因超过实时新鲜度窗口而标记 `stale`。明确来源时间更晚的收盘数据仍可归档，不能因为“不够实时”错过收盘快照。更新按来源时间比较；失败重试返回的同一快照、相同或更旧数据不能覆盖已有记录，来源状态和时间保持原样。
- 历史模式只读本地数据库，暂停行情轮询；切换热力、榜单或板块下钻不会调用实时接口。缺失日期、面板、成分会明确显示未保存，不用今日行情补齐。
- 历史从使用此功能后实际取得的数据积累。没有采集的过去日期不能凭日期选择器还原，也没有后台常驻采集或自动历史回填。

记录位于原数据目录 SQLite 的 `market_panel_snapshots` 表，按 `(date, panel_key)` 保存版本、来源、数据时间、保存时间和 JSON 数据。普通“清理行情缓存”不删除它，重启后仍可读取；没有自动删除旧日期的策略。

## 新增面板

复用按日期、面板存储，不为新面板新增数据库列：

1. 在 `packages/contracts/src/market-history.ts` 为面板定义数据契约、校验和唯一 key；加入 `MARKET_HISTORY_PANELS` 以参与完整性提示。
2. 在对应 Host 成功取数路径调用现有 `archiveMarketPanel`，传入原数据、来源和可确认的市场日期。独立 RPC 独立归档，不能让慢面板阻塞首页其它数据。
3. 在历史视图通过 `marketHistoryPanel` 读取所选日期；缺失时显示未保存，禁止回退实时 RPC。
4. 增加成功归档、失败不覆盖、跨日归属、历史无实时请求测试。面板 JSON 结构不兼容时升级版本并提供读取兼容，不能把旧记录直接当新结构使用。

日期列表和快照读取通过认证的 `market.history.list` / `market.history.get` RPC，客户端不指定文件路径或行情 URL。

## 宏观数据

`#/dashboard/macro` 按日期范围查询沪深300指数、ETF规模及占比；使用当前已核实的历史时间序列，不再按整图生成日期选择快照。

### 查询与持久化

- 默认截至最近应收盘工作日向前五年；周末及15:05前回退工作日。这个默认日期策略不是节假日交易日历，实际观测日期以中证指数来源为准。可选择更早的任意区间，单次最长五个日历年，闰日回退到2月28日；前后端均拒绝无效、倒序或未来日期。
- `market.macro.query` 先返回本地数据及任务状态，缺口排入宿主后台；“更新数据”可主动重试。页面每两秒观察正在运行/排队的任务，离开页面只取消观察。任务结果同时返回其所属范围，互不相交区间的失败不会标记当前展示数据为刷新失败。
- 时间序列按月分桶保存到 `(月份首日, macro.series)`，每个桶只合并该月的实际观测和必要来源信息；近期参考桶保留一个真实前月官方锚点用于口径校验。月份首日仅为存储分区键，实际数据日期仍在观测及来源元数据中。不同查询范围合并进同一月份，不每天复制整张五年窗口。原始份额/净值继续用 `macro.etf.inputs`。不新增数据库表/列，不因查询更早范围或清理行情缓存删除数据。
- 读取旧版六个宏观分项归档作为兼容输入。新路径不创建每日整图快照；已有 `macro.chart` 不删除、不改写。今日市场其它面板的历史选择仍只读。
- 多区间按各分项实际获取时间合并同日观测，官方月报始终优先于参考值。范围外的数据不进入图表；本地保存超过五年不等于单图可以展示超过五年。

### 后台更新

- DSH宿主启动时启用调度，常驻时每天北京时间20:00更新默认区间；启动时补跑最近遗漏的晚间任务，不逐天重复全量补跑。只追加新日期、补缺和复查近期来源；不盘中轮询。
- 待办范围及尝试时间保存在现有settings，成功批次保存后才继续。活动范围留在持久队列，关闭宿主暂停，重启恢复；无需页面打开。宿主完全关闭时不会继续网络请求，不额外安装系统服务。
- 同一宿主串行执行范围，区间内六个面板独立推进；待办的重复/重叠范围在合并后不超过五年时合并。单面板失败不阻塞其它面板，无进度停止，不冒充补齐。
- 自动缺口请求六小时退避，手动更新60秒冷却；来源没有历史观测时保留缺口。每日滚动窗口已覆盖的旧重试区间不重复排队，仅续补范围外日期；若本次更新被冷却拦截，旧待办继续保留。免费接口不承诺任意年代均可补齐。

### 数据口径

- 日频ETF规模 = 交易所同日份额 × 东方财富未复权单位净值，不是净流入。按已核实上市/清算日期纳入目录；缺任一应纳入产品的同日数据，则该日总规模留空，不插值。
- 四只指定产品：510300、510310、510330、159919。下图红色为四只规模，蓝色堆叠为其它已核实目录产品，上边界为总规模；目录仍可能遗漏历史产品。
- 单位净值保留历史原始观测；近期按分页增量更新，查询更早区间时读取完整公开净值序列并合并。交易日历来自指数，不能用净值日期补造交易日。
- 上交所日份额全表、深交所窗口分页，每批最多8个交易日、31自然日窗口，串行请求间隔300ms；来源连续失败3次熔断5分钟。
