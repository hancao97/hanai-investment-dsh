# ADR-0004：开放专家对谈使用独立业务索引与 DSH Session

- 状态：已接受并实现
- 日期：2026-08-23

## 背景

既有“继续对话”必须先完成一份单只股票的正式研判，后续消息也继承该股票、报告和工作区上下文。用户需要另一种入口：不选股票、不生成报告，可以围绕行业周期、商业、市场、决策或近期事件与一位专家持续讨论，并新增孙宇晨视角专家。

若直接放宽研判模型，会让报告状态机、`REPORT.md` 封存和证券字段出现大量空值；若为开放对谈新建消息表，又会破坏 DSH 是会话唯一事实源的架构原则。

## 决策

### 1. 对谈是独立业务类型

开放对谈不是“无股票研判”，也不是研判报告的一个状态。Hanai 新增 `expert_chats` 业务索引，只保存：

- 对谈标题、专家与专家快照版本；
- opaque `dshSessionId`；
- 模型选择、Turn 状态、创建/更新时间和最近错误。

消息、推理、工具活动、队列、附件与完整 Turn 历史仍只由 DSH Session Persistence 保存。Hanai 不新增 `messages`、`turns` 或 `activities` 表。

### 2. 每次对谈对应一个独立 Session 和工作区

目录为：

```text
~/.hanai-investment-dsh/expert-chats/<chat-id>/workspace/
├── AGENTS.md
└── .agents/skills/<master-id>/...
```

对谈工作区复制不可变专家能力快照，但使用专门的开放对谈 `AGENTS.md`：允许正常澄清、检索和工具调用；不绑定证券；不要求交付结论；禁止创建或改写 `REPORT.md`。切换专家必须创建新对谈，不能在原 Session 中静默换人。

创建空白对谈时不发送合成 prompt，避免在历史中伪造用户消息。用户提供开场问题时，DSH 收到的用户消息就是原始问题；工作区合同承载系统约束。

### 3. 专家能力显式分流

现有段永平、混江龙、查理·芒格和沃伦·巴菲特同时支持个股研判与开放对谈。孙宇晨标记为 `chatOnly`：

- 在专家中心和专家对谈入口可见；
- 不出现在新建个股研判选择器；
- Host 在 `judgement.create` 再次校验，客户端过滤不能被 RPC 绕过。

### 4. 孙宇晨使用“视角模拟”而非身份冒充

用户指定的 [上游开源示例](https://github.com/alchaincyf/nuwa-skill/tree/main/examples/sun-yuchen-perspective)提供注意力套利、叙事覆盖、身份杠杆、场景切换、快速复制与资本杠杆等分析框架。Hanai 版本保留这些镜头，并针对行业周期补充需求、供给、库存与利用率、资本开支、价格利润和拥挤度检查。

产品在创建对谈时显示“基于公开资料的 AI 视角模拟，非本人观点”声明，首次回答也必须披露；详情页不再重复显示常驻声明，以免挤占消息空间。具体公司、市场、人物、数字或近期事件必须先联网核验并注明来源日期。人设不得覆盖事实、安全、法律与伦理边界，也不得把操纵市场、欺骗或规避监管转化为可执行建议。

“永远缺某种资源”一类表述只作为待证伪的周期假设，回答必须给出阶段证据、领先指标、反证和失效条件，不作为收益承诺。

### 5. 产品入口与生命周期

新增一级导航 `#/expert-chats` 和详情深链 `#/expert-chats/:id`。页面由左侧对谈记录和右侧专家选择/DSH ChatPanel 组成；创建器支持专家选择、可选开场问题和专家提供的建议问题。

删除对谈前检查 DSH Session 是否运行。空闲时先归档 Session，再删除本地专家快照和业务索引；运行中拒绝删除。Host 重启后恢复运行状态，无 Session 的半成品标记为可删除失败记录。

## 后果

### 正面

- 用户无需先选股票或等待报告即可与专家讨论任何主题。
- 研判报告状态机、正式快照和开放对谈保持清晰边界。
- DSH 继续独占会话数据，现有 ChatPanel 的队列、steer、取消、审批和历史分页全部复用。
- 专家快照可审计，孙宇晨的人物模拟、时效事实和投资风险在 UI、工作区与 Skill 三层都有边界。

### 代价

- 完整备份仍需要同时保存 Hanai 业务根与 DSH Session 数据。
- `expert_chats` 标题只是业务索引；对谈正文不能仅靠 Hanai SQLite 恢复。
- 新增一级页面改变了旧版五页信息架构，因此 ADR-0001 的“五页固定”约束由本决策有意修订为六页。

## 被否决的方案

### 复用 `judgements` 并允许证券字段为空

会把报告生命周期、证券研究上下文和开放对话混为一体，产生大量条件分支和错误封存风险。

### 只在前端创建临时 DSH Session

重启后无法恢复专家、标题和产品入口，也无法安全归档或清理工作区。

### 将孙宇晨加入个股研判

用户明确要求其出现在开放聊天专家中；其上游能力定位更适合行业、注意力和叙事判断。首版不把它包装成正式个股报告方法论。
