## 1. 为什么段永平拒绝沃尔玛百万台 VCD OEM 订单？

### Skill 生成回答

**结论：这笔订单的金额很大，但业务方向不对。**

公开回忆中的关键不是价格，而是长期资源配置。步步高要把产能、组织注意力和用户关系放在自有产品、自有品牌上；一旦同时做 OEM，短期收入会上去，却可能削弱自己的产品和品牌。拉长到十至二十年，专门做代工的企业会有更好的成本优势，两头兼顾很可能两头都做不到最好，所以没有进入价格谈判，直接拒绝。

这更准确地说是“短期大单不能伤害长期主线”，不是反对所有大客户或所有多业务经营。现有材料还注明，最早提出“不做 OEM”的是陈明永；订单细节和决策效果主要来自本人后来的公开回忆，外部材料没有完成独立事实核验。

### 研究材料中的实际立场

1. `05-decisions.md` 案例 4 记录：提出订单的是“沃尔玛供应商”，规模约 100 万台 VCD；步步高直接拒绝，未进入价格谈判。
2. 本人公开理由是：代工会占用组织和产能；十至二十年看，专职代工企业更有成本优势；步步高若同时做代工和自有品牌，既难成为最佳代工厂，也会削弱自有品牌。
3. `01-writings.md` C04、C10 将该案例放在消费者导向、长期视角和经营禁区中，但明确这些是研究综合；不能把“消费者价值”写成当时唯一、逐字的本人理由。
4. `05-decisions.md` 还保留两个边界：最早提出“不做 OEM”的是陈明永；长期品牌路径不能被写成这一个决定单独造成的可识别收益。

### 审计

- **一致性标记：方向一致。** 回答抓住了真实决策变量：长期聚焦、自有品牌、资源占用和专职代工的成本优势。
- **过度断言**：没有实质性过度断言。需要继续避免写成“沃尔玛直接向步步高下单”；研究材料只支持“沃尔玛供应商提出约百万台订单”。也不能断言该拒单单独造就了后来的品牌成功。
- **遗漏例外**：已保留“反对资源混用，不等于反对所有多品牌、多公司或外部订单”的边界，并注明陈明永的首倡归属。
- **冒充风险**：低。回答使用中性转述，没有用第一人称冒充亲历，也没有把后期回忆包装成当时会议的逐字动机。

## 2. 好公司是否永远不需要卖？

### Skill 生成回答

**不是。“好公司不需要卖”是长期持有的短句，不是永久禁售规则。**

买入时应当以长期持有为意向，避免被短期价格牵着走。但继续持有仍是一个今天的决定，可以理解为按当前价格重新买入。只要公司仍然看得懂、原始逻辑没有被证伪，而且它仍是机会成本下更好的选择，就没有必要因为涨跌频繁交易。

需要卖出的情形至少有两类：一是原始判断、商业模式、文化或所持工具被证伪；二是出现真正看懂、风险收益和机会成本明显更好的公司。前者要停错，后者可以换仓。因此，长期持有是默认意向，不是“永远不卖”。

### 研究材料中的实际立场

1. `02-conversations.md` 记录了时间上的明确细化：2018 年整理稿对“何时卖苹果”以“好公司不需要卖”作短答；2025 年长访谈则明确说投资是要卖的，长期持有只是买入时的意向，若有真正看懂且机会成本更好的公司，可以换。
2. `01-writings.md` C09 把持有定义为与当前最佳替代机会比较，并记录“持有等于在当前价格重新买入”；C10 明确写出长期不等于永不卖，买入理由消失、公司买错或机会成本明显改变时应纠错。
3. `05-decisions.md` 提供行为对照：卖出大量 GE 转向更懂的苹果，符合机会成本换仓；卖出大部分网易后本人认为卖早了，说明“会卖”不等于每次卖出都正确。
4. 材料同时表明，不能把“价格涨了”“达到旧目标价”单独当作机械卖出条件；判断仍依赖对企业、当前价格和替代机会的比较。

### 审计

- **一致性标记：方向一致。** 回答没有复读 2018 年金句，而是采用了 2025 年更完整的机会成本口径。
- **过度断言**：没有实质性过度断言。需要避免两个相反的绝对化版本：“好公司永远不卖”以及“只要估值高就必须卖”。研究材料支持的是相对机会成本和理解变化，不是单一估值阈值。
- **遗漏例外**：已覆盖买入逻辑被证伪和更好机会两类主要例外。还应保留实践并不完美：网易卖早、GE 后来被重新判断为买入逻辑错误，都说明该框架不能保证卖出决策正确。
- **冒充风险**：低。回答没有声称知道未公开的当前持仓或私人卖出计划。若引用“好公司不需要卖”，必须继续标明它来自 2018 年经整理短答，而不是无时间边界的逐字总原则。

## 3. 借钱或使用保证金投资是否可以？

### Skill 生成回答

**对普通投资者，实用答案是不要借钱投资；保证金则是明确的硬禁区。**

核心不是利率高低，而是外部追缴、期限错配或被迫平仓可能让一个原本可以等待的长期判断变成永久损失。看懂一家公司，也不能消除融资方在错误时间收回资金的风险。所以，高度集中如果存在，也必须和长期自有资金、无保证金绑定。

但“借钱”不能把所有负债机械混成一类。公开材料显示，他早期买网易时承认用过有抵押、可快速偿还的便利借款；对规模很小、极长期、低利率、无担保且不会触发追缴的资金，也曾作为不同风险类型讨论。这些是历史例外和分类细化，不是面向一般投资者的杠杆许可。经营中的短期周转、应付账款和长期有息扩张也应分别分析，不能直接等同于证券保证金。

### 研究材料中的实际立场

1. `01-writings.md` C07 记录其反复总结的三类重大错误来源：做不懂的事、借钱或使用保证金、做空；个人投资中的简化规则接近“不借钱”。
2. `02-conversations.md` 片段 23 保存了关键追问链：他先否认满仓后借钱的说法，被具体材料追问后承认“好像说过一次类似的话”，再将其解释为有抵押、可快速偿还的借款；主要禁区被细化为可能被强平的 margin，给不熟悉者的简化规则仍是“不借钱”。
3. `05-decisions.md` 案例 16 再次区分：网易时期的转账便利借款、极少数长期无担保低息小额债，以及明确不再使用的保证金融资。其苹果高集中案例同时明确“不用保证金”。
4. 三份材料都提醒，不应把个人证券保证金、企业长期有息扩张、短期经营周转、应付账款和其他负债压缩成同一种风险。

### 审计

- **一致性标记：方向一致。** 回答把“保证金硬禁区”“一般人的简化规则是不借钱”和“历史上存在窄例外”同时保留，没有用例外反转原则。
- **过度断言**：没有实质性过度断言。必须避免说“任何形式、任何期限的负债都绝对禁止”；也不能反向说“只要不会强平就可以借钱投资”。材料只支持风险分类和少量历史例外，不支持一套普遍的杠杆许可条件。
- **遗漏例外**：已覆盖网易便利借款、极长期无担保小额资金和经营负债分类。还需注意：现有材料中的例外多来自经编选问答，不能据此推断其当前账户融资安排。
- **冒充风险**：低。回答将例外限定为公开历史材料，没有声称本人现在如何融资，也没有把研究者对风险结构的归纳伪装成其逐字表述。

## 总判定

# PASS

三题均为**方向一致**，没有出现会反转行动结论的遗漏，也没有第一人称亲历冒充、伪造引语或把未公开动态事实写成本人当前立场。当前 Skill 足以在这三项已知问题上生成符合研究材料的回答，尤其正确保留了两个容易被金句压平的边界：

1. “好公司不需要卖”不等于永久禁售，2025 年公开材料已用机会成本明确细化。
2. “不借钱”是一般投资者的简化规则，保证金是硬禁区，但历史便利借款和不同性质的经营负债不能混为一谈。
