## 总结

当前 Skill 已达到“激活后基本可执行”的水平，强项是激活精度、事实工具政策和身份边界。最弱的两个维度是：

1. **问题路由：3/5**。已有事实型、框架型、混合型分类，也列出了投资、组织、人生三个分析清单，但没有把问题明确路由到主模型、辅模型和默认动作。Agent 仍需自行推断，容易把 6 个模型铺开。
2. **边界/停止条件：3/5**。已有投资风险硬边界和身份边界，但缺少研究何时足够、来源冲突如何收口、工具不可用时如何降级、何时值得追问等操作性停止条件。

建议共 **4 项**，均为局部插入或单行替换，不改变现有激活条件、人物立场或研究结论。

## 干跑 1：片仔癀股票

**Prompt**

> 用段永平分析片仔癀这只股票。

### 简版预期输出

结论：在核验最新经营数据和当前估值前，不能判断片仔癀是否值得买。先查带日期的最新年报或中报、后续公告、当前股价与市值、核心产品收入和量价变化、现金流与资产负债、渠道和库存信号、原料或监管风险，再判断消费者价值能否持续转化为现金流，以及当前价格相对其他机会是否有足够余量。

如果当前无法使用检索、行情或监管工具，应停在研究清单和条件性框架，不凭记忆补齐事实，也不给当前买卖结论。缺少用户收益要求、持有期限和机会成本时，不报伪精确买入价。

### 审计

| 检查项 | 结果 | 说明 |
|---|---|---|
| 是否激活 | PASS | 用户明确说“用段永平分析”。 |
| 问题分类 | PASS | 具体股票，属于事实型；若进一步讨论买入决策，也带有混合型成分。 |
| 是否先查最新资料 | PASS | Skill 用“必须”要求先检索，并要求标明数据日期；不能凭模型记忆直接评价片仔癀。 |
| 工具与来源顺序 | PASS | 应先看交易所、公司定期报告和公告，再用官网、管理层原始材料、权威行业数据补充。 |
| 模型选择 | PARTIAL | 应以模型 3“消费者价值到现金流”和模型 5“懂-估-配”为主，但现有 Skill 没有显式路由，Agent 需自行选择。 |
| 停止/失败回退 | PARTIAL | Skill 没定义最低证据集、研究停止点或工具不可用时的固定降级动作。 |
| 输出边界 | PASS | 数据不足时不应给伪精确价格；应列证伪条件，不以股价下跌代替逻辑证伪。 |

**判定**：股票题的关键安全行为已经存在，即先查最新资料而不是凭记忆回答；主要缺口是如何判断“已经查够”和工具失败时如何稳定收口。

## 干跑 2：创始人交班

**Prompt**

> 用段永平的方法判断创始人是否该把业务交给职业经理人。

### 简版预期输出

结论：先别问是不是“职业经理人”，先问有没有价值观合适、能力合格、愿意承担结果的人，以及组织规则能否在创始人不在场时继续运行。

方向和原则仍由创始人或董事会守住，方法和执行应逐步交给负责人。可以先从一块业务开始，写清授权边界、结果责任和不可触碰的原则，经历“指导—协商—授权”后再决定是否全面交班。若负责人不合适、制度只靠创始人口头维持，或创始人授权后仍持续遥控，就不具备真正交班的条件。

### 审计

| 检查项 | 结果 | 说明 |
|---|---|---|
| 是否激活 | PASS | 用户明确要求“用段永平的方法”。 |
| 问题分类 | PASS | 抽象组织管理问题，默认是框架型，无需为展示框架而联网。 |
| 问题重写 | PASS | 从身份标签“职业经理人”改写为负责人合适性、分阶段授权和机制独立性。 |
| 模型选择 | PARTIAL | 最合适的是模型 4，辅以模型 2、模型 6；现有 Skill 没明确主次，可能罗列过多模型。 |
| 事实边界 | PASS | 若用户提供具体公司或候选人，问题转为混合型并应先核验事实。 |
| 行动性 | PASS | 可以形成试点授权、边界、责任和阶段复盘，而不是停留在价值观口号。 |

**判定**：框架本身可操作，但缺少快速路由会增加输出漂移和模型堆砌概率。

## 干跑 3：离开高薪工作

**Prompt**

> 用段永平想想，我要不要离开高薪但长期不喜欢的工作。

### 简版预期输出

结论：高薪不是继续留下的充分理由，长期不喜欢也不是立刻裸辞的充分理由。先分清不喜欢的是工作内容、组织环境，还是某个暂时阶段；再去掉面子、沉没成本和旁观者评价，看这份工作是否长期违背兴趣、能力和应承担的责任。

如果方向已经确认不合适，继续等“赚够了再走”往往只是拖延；但家庭责任和现金缓冲是真约束。更稳妥的动作是设定退出期限，准备必要的生活储备，并用低成本方式验证下一份工作，而不是在情绪最高点辞职。若还不能判断方向是否错，先做一个有期限的验证，不把短期疲惫误判为长期不合适。

### 审计

| 检查项 | 结果 | 说明 |
|---|---|---|
| 是否激活 | PASS | “用段永平想想”属于明确点名并请求使用该方法。 |
| 问题分类 | PASS | 抽象人生选择，默认直接运行模型，不需要联网。 |
| 模型选择 | PARTIAL | 应以模型 1 和模型 2 为主；现有 Skill 未明确限制把投资模型机械迁移到人生题。 |
| 边界与停止 | PARTIAL | Skill 要求必要时改写问题但不机械追问，却没说明何种缺口值得追问、最多追问多少。 |
| 身份边界 | PASS | 应直接给顾问式分析，不说“我当年如何”，也不把结论写成段永平本人的私下意见。 |
| 简洁性 | PASS | 两个模型足够，不需要展示完整模型编号、人物案例或研究过程。 |

**判定**：能产生有区分度的职业决策分析；增加路由优先级和追问停止条件后会更稳定。

## 最弱维度一：问题路由

### 建议 1/4：增加激活后的快速路由表

**位置**：放在 Step 1 的事实型/框架型/混合型表格之后。

**目的**：让 Agent 在激活后立即选定主模型、必要辅模型和默认动作，减少把全部模型铺开的概率。该表只负责激活后的执行，不参与触发判断。

**可直接应用文本**

```markdown
#### 快速问题路由

本表仅在Skill已按“激活边界”触发后使用，不扩展触发条件。

| 问题 | 主模型 | 可选辅模型 | 默认动作 |
|---|---|---|---|
| 具体企业或股票 | 模型3：消费者价值到现金流 | 模型5；涉及治理时加模型4或6 | 先查最新事实和估值日期，再给条件性判断 |
| 创始人、继任、授权或组织 | 模型4：分阶段授权 | 模型2、6 | 先判断人是否合适，再检查原则、责任和制度是否可独立运行 |
| 职业、合作或人生取舍 | 模型1：本分-平常心 | 模型2；涉及承诺时加模型6 | 先剥离面子和沉没成本，再区分方向错误与执行困难 |

每次只选1个主模型，必要时补充不超过2个辅模型。没有证据支持时，不把投资模型机械迁移到人生问题，也不把经营案例写成本人对当前个案的立场。
```

### 建议 2/4：收紧形成判断中的模型数量

**位置**：替换 Step 3 默认输出顺序中的第 4 项。

**目的**：与快速路由形成闭环，使输出默认围绕一个主判断展开。

**可直接应用文本**

```markdown
4. **框架分析**：按快速问题路由选择1个主模型；确有增量时再补充不超过2个辅模型，不枚举无关模型。
```

## 最弱维度二：边界/停止条件

### 建议 3/4：增加事实研究检查点和停止条件

**位置**：放在 Step 2 三类分析维度之后、Step 3 之前。

**目的**：定义“查够了”的最低标准，避免无边界扩展搜索，也防止只查到一条材料就仓促下结论。

**可直接应用文本**

```markdown
#### 事实核验检查点

具体企业或股票至少核对：最新定期报告及其后的重大公告、带日期的价格与市值、支持核心判断的经营和现金流数据，以及一个最强反证或当前风险。只收集会改变判断的事实，不为完整而堆材料。

满足以下条件即可停止研究并进入判断：

- 每个关键事实都有日期和可追溯来源，重大结论优先由一手材料支持。
- 来源冲突已按“较新的一手材料优先”处理；若冲突仍会改变结论，则保留条件判断，不强行裁决。
- 关键未知项已被写成信息缺口、条件或证伪点；继续增加来源已不会改变当前行动建议。
```

### 建议 4/4：增加追问阈值与工具失败回退

**位置**：放在 Step 1 末尾或 Step 2 开头。

**目的**：规定何时问用户、何时直接带假设回答，以及无法获得最新事实时必须停在哪里。

**可直接应用文本**

```markdown
#### 澄清与失败回退

- 只有缺失信息会改变问题类型、主模型或行动方向时才追问；一次合并为1个关键问题。其余情况先说明假设并继续分析。
- 股票题缺少收益要求、持有期限或机会成本时，可以分析企业与风险，但停止在条件性估值，不给精确买卖价。
- 事实题若检索、行情或监管工具不可用，或最新资料无法确认，应明确说明未完成最新核验；不得用记忆补齐。此时只给研究清单或条件性框架，不给当前事实判断。
- 框架题在给出结论、1个主模型、必要辅模型、一个主要反证和下一步行动后即可停止，不为展示人物知识追加无关案例。
```

## 最终结论

不建议改动激活条件、事实来源优先级、6 个核心模型或身份规则。优先应用上述 4 项流程级修改：先补“问题到模型”的路由，再补研究、追问和工具失败的停止条件。这样能让 Skill 更接近 Phase 5 所要求的“激活即执行”，同时不牺牲现有事实严谨性、输出克制和非冒充边界。
