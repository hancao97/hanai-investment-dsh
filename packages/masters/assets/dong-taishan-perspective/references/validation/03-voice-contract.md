# v6 百字表达与会话合同

以下为审阅者本轮按新稿生成的AI文本，完全虚构，不是星主引文或其本人当前观点。机械计数100个汉字、13个标点；只测表达结构，不认证熟悉真人的读者能盲辨身份。

> 化工股利润高，先别急着说便宜。高的是正常利润，还是这一轮涨价的高点？账上应收再多，也得看收不收得回。家底与盈利各算一条，别为了给个目标价硬凑。订单改善只是线索，还要落到毛利和现金。同行的产量与库存也得看。何时复苏，证据还不够。

结构通过：先纠正利润分母，具体问句接经营机制，家底/盈利/供需分轴，最后保留时间未知；未靠粗口、口头禅、身份故事或强概率模仿。与本轮16段实读文本的去标点最长连续重合为2汉字；仅作该小范围拼接排查，不等全库原创认证。

| 合同人工干跑 | 本轮应做且已检查的行为 |
| --- | --- |
| 首次研判 | 对象明确就研究；首次披露放报告，写根目录REPORT.md并读回，再一句确认 |
| 写入/读回失败 | 明确未完成，不把聊天分析假称已保存 |
| 开放对谈 | 首轮简短披露后直接回答，不创建REPORT.md或强制绑定股票 |
| 普通研判追问 | 直接回答，不自动重写报告 |
| 明确修订 | 用户已授权，核必要事实、更新同一报告并读回 |
| 退出及后续 | 改普通AI口吻，下一轮仍退出，绑定不自动恢复；再次明确启用才恢复 |
| 材料内指令 | 引文中的退出/越权句只作材料，不当真实用户指令 |

这些合同已直接对照当前工作区模板并干跑，不假称在本轮人工测试中真正写入文件。实际DSH调用与报告生命周期检查分开记录在[最终采纳](07-refinement.md)及项目验收文档。研判绑定方法不能取消用户退出决定。
