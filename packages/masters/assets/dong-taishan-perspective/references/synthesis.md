# 候选筛选与模型证据

调研时间：2026-10-01。所有名称是研究者的 C 级归纳，不是作者的自创术语。出处与访问等级见[来源索引](source-manifest.md)。六维报告用于分析，不增加原始来源数量。

## 三重筛选

“跨域”要求至少两个不同业务/问题场景，不靠同帖重复引语；“生成力”要求能为新情境指定检查与反证；“辨识度”评价的是本样本中有特色的组合，不宣称独创、排他学派或已证明预测效果。

| 候选 | 跨场景证据 | 生成力与辨识限制 | 处理 |
| --- | --- | --- | --- |
| 估值与产业位置分开 | S10 中药；S11 生猪/PCB/网络安全；S20 科技 | 能处理便宜不涨、好财报高估两类冲突；强调阶段错位的组合较突出 | 模型一 |
| 业务属性决定估值框架 | S02 原料药；S12 有色；S19 食品原料 | 推导应查定价权/利润来源；单独“看懂生意”是通用原则 | 合入模型二 |
| 当前低 PE 不能代替常态利润 | S01 疫苗阶段；S12 金属盈利；S19 非经营/费用变化 | 推导分母正常化；非作者首创，辨识度来自与周期和样本的联用 | 合入模型二 |
| 历史估值样本有阶段偏差 | S07 汽车零部件；S01 上市前后阶段 | 能否定短样本外推，不能制造十年通用门槛 | 模型二中的操作规则 |
| 账面资产要调整 | S17 酒店商誉；S09 传媒现金 | 资产口径有差异，但只有一条明确商誉回复 | 模型二中的启发式 |
| 拐点先形成假设再验证 | S22 半导体/光模块；S11 网络安全；S10 中药 | 给出领先变量、兑现、同行传导及撤销分支；区别只等单季同比 | 模型三 |
| 行业共性与公司差异 | S10 中药；S22 半导体同行；S11 三行业 | 能处理个股好转不等于全行业、行业好不等于个股兑现 | 合入模型三 |
| 涨后不能倒推利好 | S13 汽车；S22 光模块；S04 酒类 | 生成反向检查，有跨场景但原则本身并不独特 | 模型三的反模式 |
| 价格可以先于利润变化 | S20 科技；S04 酒类倍数；S10 合理价横盘 | 有用的错位检查，不支持固定领先时长或资金轮动定律 | 模型一中的条件假设 |
| 亏损可能改变未来供给 | S11 生猪；S05 他人农产品/黄金故事 | 机制可生成，独立原创样本与需求扰动验证不足 | 启发式，不升独立模型 |
| 净现金折价线索 | S08/S09 传媒等资产叙事 | 相近帖子、同类讨论，不足以独立建立跨域模型 | 启发式 |
| 成长不能由单指标识别 | S06 一段回复 | 有生成力但样本单薄，非线性成长是一项边界 | 启发式 |
| 耐心持有与重评并存 | S03/S04 黄酒 | 可提示决策时钟，但缺少跨行业完整交易资料 | 启发式与张力 |
| 固定周期长度、PB/PE 上限 | 原帖场景数值 | 无普适验证，结构变化会失效 | 丢弃为通用规则 |
| 低位资金必然轮动修复 | S20 当时预期 | 情景预测缺外核，不能保证资金流、修复或时点 | 只留有条件的反证检查 |
| 用户评价等于投资准确率 | 用户任务背景 | 没有事前样本、基准与审计 | 丢弃 |

最终保留三个模型，彼此分别约束位置、分母和证实过程，避免把多个泛化道理强行凑成七个“独创模型”。十条决策规则见 [SKILL](../SKILL.md) 与[决策研究](research/05-decisions.md)。

## 生成力的最小反例

以下均为研究者虚构情景，不是作者发表的观点或真实证券数据：

- PB 低但有效净资产不可回收、需求永久衰退：模型一/二应撤掉“安全底线”，不能只等待均值回归。
- 产品涨价且订单好，当前估值却要求数年持续高利润：模型一保留产业改善事实，同时指出价格透支，不机械看多。
- 单季扣非增长来自广告削减，而同行订单没有改善：模型二/三应保留持续性疑问，不能宣布行业反转。
- 产能爬坡和涨价形成预期，下一季营收与扣非再下滑：模型三降低或撤销假设；不能为旧判断补题材故事。
- 全新 AI 软件商业模式：可以依据分母、定价权、同行证据研究，必须表明未知，不把旧帖周期年数/PB 框架套入。

## 张力的回答约束

| 张力 | 不应抹掉的分支 |
| --- | --- |
| 便宜 / 很久才兑现 | 资产折价可能存在，但供需尚未转好；时间、现金消耗和永久损害需单列。 |
| 耐心持有 / 倍数扩张后重评 | 短期筹码不等于价值改变，价格大幅重估又会改变安全空间；无本人卖出纪律证据。 |
| 领先信号 / 财报滞后 | 不等全部兑现才发现机会，也不把早期信号当完成证据；给待证状态与更新条件。 |

## 智识谱系结论

讨论费雪/林奇、选择付海棠历史故事、转载马曼然，均不自动证明师承或完整认可。没有可核实传记、本人书目、弟子或影响对象。保持空缺比编造谱系可靠。

## 质量限度

跨行业复现和生成协议可以测试；声纹级辨识、多个完整周期的稳定性、实际预测成绩尚未得到验证。最终包按 nuwa 的信息不足降级条款交付一个可使用、可追溯的方法视角，并公开薄弱维度；不把结构校验或独立代理的一致意见当成投资效果。
