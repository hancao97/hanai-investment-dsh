## 时间线表

| 时间 | 事件 | 对思维的影响 |
|---|---|---|
| 1930 | 出生于 Omaha, Nebraska | 地方主义、美国中西部商业伦理、长期留在能力圈 |
| 1941 | 约 11 岁买入第一只股票 Cities Service | 早期体验价格波动、后悔过早卖出 |
| 1947-1951 | Wharton / University of Nebraska / Columbia Business School | 在 Columbia 直接受 Benjamin Graham 影响 |
| 1954-1956 | Graham-Newman 工作 | 学习证券分析、安全边际、市场先生 |
| 1956 | 回 Omaha 创立 Buffett Partnership | 小资金高约束，形成合伙人沟通文化 |
| 1959 | 认识 Charlie Munger | 逐步从烟蒂股向优质企业转变 |
| 1965 | 控制 Berkshire Hathaway | 后称买入纺织业务是错误，成为错误复盘母案例 |
| 1967 | Berkshire 收购 National Indemnity | 进入保险，获得 float 引擎 |
| 1969 | 关闭 Buffett Partnership | 机会不足时宁可停，不为费用继续下注 |
| 1972 | Blue Chip/Stamps 体系买 See's Candies | 认识品牌、定价权、轻资本优秀企业的价值 |
| 1973-1974 | 买 Washington Post | 恐慌期以低价买优质资产 |
| 1976-1996 | GEICO 持续投资并最终全资 | 从早期理解的企业持续加码 |
| 1983 | 写下 owner-related principles | 把股东筛选和经营原则制度化 |
| 1988 | 买 Coca-Cola | 消费品牌和全球分销复利典型 |
| 1991 | Salomon crisis | 强化声誉、监管、新闻纸测试 |
| 1993 | Dexter Shoe | 后来成为「业务错 + 支付货币错」典型 |
| 1998 | 收购 General Re | float 扩张伴随复杂风险管理 |
| 1999/2001 | Fortune 股市估值长文 | 宏观估值框架：利率、利润/GDP、市场总值/GNP |
| 2006 | 宣布大规模捐赠计划 | 财富观从复利积累转向社会分配 |
| 2008-2011 | 金融危机中投资 Goldman Sachs、GE、Bank of America 等 | 保守资产负债表换来危机选择权 |
| 2009 | 收购 BNSF | 对美国经济和基础设施长期下注 |
| 2015 | Berkshire 50 周年 | 公开回顾制度、Munger 影响和后 Buffett 时代 |
| 2016-2018 | 建立 Apple 大额持仓 | 能力圈扩展到消费生态/品牌 |
| 2020 | 疫情后清仓航空股 | 承认行业判断和极端风险错误 |
| 2020 起 | 投资日本五大商社 | 国际化但仍按现金流、价格、股东回报判断 |
| 2022 起 | 增持 Occidental | 能源现金流和现实主义配置 |
| 2023-11-28 | Charlie Munger 去世 | 失去长期思想合伙人，2024 后会议风格改变 |
| 2025-05-03 | 年会宣布计划 2025 年底卸任 CEO | 个人 CEO 时代结束，进入制度传承阶段 |
| 2026-01-01 | Greg Abel 接任 Berkshire CEO | SEC proxy 确认，Buffett 继续任 Chairman |
| 2026-02-28 | Greg Abel 发布首封 CEO 股东信 | 年报写明 Buffett 仍每周五天在办公室、可参与资本配置等 |

## 最近 12-18 个月动态

1. 2025-02-22：Buffett 发布 2024 letter，集中讨论错误、Greg Abel 将接替其写年度信、日本商社长期持有、Berkshire 60 年。
2. 2025-05-03：Buffett 在 2025 年会宣布将于 2025 年底卸任 CEO。
3. 2025-05-04：Berkshire 董事会投票任命 Gregory Abel 自 2026-01-01 起担任 President and CEO。
4. 2026-01-01：Abel 正式接任 CEO；Buffett 保留 Board Chairman。
5. 2026-02-28：Berkshire 2025 annual report/Abel 首封信发布，强调文化、长期股东、保险核心和资本配置延续；信中写 Buffett 仍在办公室五天并可供管理层咨询。
6. 2026-05-02：Abel 主持第一场后 Buffett CEO 时代年会；AP 报道风格更偏详细经营讨论。
7. 2026-07：AP 报道 Buffett 接受 CNBC 采访，解释加速慈善捐赠、Gates Foundation 调整、2034 前处分剩余 Berkshire 股份计划；同文称他仍支持 Abel。
