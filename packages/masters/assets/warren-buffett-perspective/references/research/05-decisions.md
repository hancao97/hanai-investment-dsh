## 成功案例共同结构

1. 业务可理解：保险、糖果、饮料、铁路、银行、消费品牌、商社。
2. 竞争优势可持续：品牌、成本优势、网络/渠道、监管/规模壁垒。
3. 管理层可信：不需要频繁干预。
4. 价格给出安全边际：不是绝对低价，而是相对未来现金流便宜。
5. 时间站在一边：业务能长期再投资或吐现金。
6. 资本来源稳定：float、留存收益、低税摩擦和长期股东基础。

## 错误案例共同结构

1. 把资产便宜误认为业务好：Berkshire textile。
2. 低估技术/行业变化：IBM、Dexter。
3. 低估极端情景：航空股。
4. 好公司买贵：Precision Castparts。
5. 用错误货币支付：Dexter 用 Berkshire 股票支付，机会成本巨大。
6. 对人和管理层判断错误：2024 letter 承认经理人能力或忠诚判断也会错。

## 资本配置模式

- 优先级：维护保险承保安全和公司韧性 → 投资现有子公司 → 收购整个企业 → 买公开市场股票 → 回购 Berkshire → 持有现金。
- 回购标准：价格低于保守估计的内在价值，且不会损害公司财务安全。
- 分红：长期不分红，因为内部配置长期更有效；个人层面通过慈善捐赠处置财富。
- 杠杆：极度保守，尤其不让短期资金需求左右长期资产。

## 反模式

- 为了行动而行动。
- 因为别人赚钱而追逐热门主题。
- 用复杂模型遮住不可理解的业务。
- 用短期会计利润掩盖长期经济变差。
- 不承认错误，尤其是延迟纠错。
- 管理层拿股东的钱当自己的选项游戏。

## 心智模型候选

1. 资本配置优先级模型：每一美元都要找最高风险调整后用途。
2. 低摩擦复利模型：长期少交易、少税、少错误。
3. 结构性资金模型：float/留存收益/声誉交易形成独特资本来源。
4. 错误成本模型：买错企业、买贵、用错支付货币是不同错误，可以叠加。
5. 危机选择权模型：平时保守，是为了危机时激进。
