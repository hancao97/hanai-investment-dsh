# 今日市场整页历史记录

## 目标
参考 dsh-plugin，使今日市场可按日期查看已保存的完整页面数据；所有当前面板自动持久化，未来新增面板沿用统一的历史存储机制。

全部阶段完成。

## 已确认决策
- 用户明确选择从当前 dsh-profile 创建功能分支；当前为 codex/market-page-history，基线 9291bd3。
- 复用已有独立加载、数据源优先级、乐咕宽度、缓存和手动冷却；不合并或 rebase dsh-plugin。
- 历史读取只用本地真实归档，缺失日期或面板不能混入实时数据；不伪造历史回填。
- 按面板增量保存，失败、不可用或较旧响应不能覆盖已有成功数据。
- 存储须支持新增面板，避免每新增一个面板修改 SQLite 表结构。
- 归档是持久业务数据，普通行情缓存清理不能删除；不复制参考分支的静默 90 天淘汰。

## 验收
- 当前首页指数、宽度、行业/概念热力、四类榜单都可恢复；已访问的板块下钻也不能在历史模式调用实时接口。
- 自动采集和手动刷新均保存成功结果；历史模式停止实时轮询和实时请求。
- 冷启动、重启、缺失日期、部分缺失面板、损坏数据和异步切日竞态均有测试。
- 盘中自动轮询与手动 60 秒冷却继续解耦。
- 执行 typecheck、完整 Vitest、build；实际运行验证日期切换和存储，分别报告证据范围。

## 验收结果
- 八类面板自动归档、独立宽度不阻塞、板块下钻本地读取：Host 与页面测试通过，真实 Profile 历史视图全部恢复。
- 日期缺失、部分面板缺失、损坏 JSON/不支持版本、重启、95 日期保留：测试通过；真实缺失日期与重启持久性通过。
- 历史停实时请求、迟到响应不串日、返回今日、自动轮询和冷却解耦：fake timer / 异步测试通过；真实页面切日和返回通过。
